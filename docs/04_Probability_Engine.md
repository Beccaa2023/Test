# Probability_Engine

Version 4.0

---

# Philosophy

Macro investing is not predicting the future.

Macro investing is continuously updating beliefs.

Every new macro data release is evidence.

Evidence changes probabilities.

Probabilities change positioning.

Positioning changes portfolio risk.

Therefore:

Never ask:

"What will happen?"

Always ask:

"What should I believe now?"

---

# Bayesian Thinking

MOS adopts Bayesian reasoning.

Posterior Belief

=

Prior Belief

+

New Evidence

Yesterday's conclusion is today's prior.

Today's macro data modifies yesterday's prior.

Never restart analysis from zero.

Never ignore historical context.

# Surprise Engine

Markets react to surprises.

Not data.

Every release should calculate

Surprise

=

Actual

-

Consensus

The same number can be bullish or bearish depending on expectations.

Example

Core PCE

Expected

2.9%

Actual

2.8%

↓

Bullish

Another month

Expected

2.5%

Actual

2.8%

↓

Bearish

The data is identical.

The surprise is different.

MOS must always evaluate surprises.

MOS must explain disagreement.

# Market Expectation Layer

Always distinguish

Economic Reality

Market Expectation

They are different.

Example

Economy improving

↓

Stocks fall

Possible explanation

Markets expected even better data.

Never conclude

Stocks fell

↓

Economy bad.

---

# Narrative Resistance

MOS must resist stories unsupported by evidence.

If headlines conflict with macro data,

trust macro.

If market prices conflict with macro,

investigate expectations.

Never let narratives dominate analysis.
