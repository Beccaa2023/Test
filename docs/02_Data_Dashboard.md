# Macro Operating System (MOS)

## 02. Data Dashboard

Version 4.0

---

# Purpose

The Data Dashboard defines the standardized macroeconomic data framework used throughout MOS.

Its objectives are:

- Establish a unified indicator library.
- Standardize data definitions.
- Classify indicators by importance and timing.
- Ensure consistency across all research modules.
- Reduce analytical bias caused by selective data usage.

Every engine in MOS must use this Dashboard as its single source of macroeconomic data.

---

# Data Philosophy

MOS does not collect data for completeness.

MOS collects data to answer macroeconomic questions.

Every indicator must satisfy at least one of the following purposes:

• Measure Growth

• Measure Inflation

• Measure Employment

• Measure Liquidity

• Measure Credit

• Measure Structural Change

Indicators that cannot improve macro understanding should not become core indicators.

# Importance Rating

MOS assigns every indicator an importance level.

★★★★★

Core indicators that frequently change macro views.

★★★★☆

Important confirmation indicators.

★★★☆☆

Useful supporting indicators.

★★☆☆☆

Supplementary indicators.

★☆☆☆☆

Reference only.

Importance reflects macro relevance, not media attention.

---

# Timing Classification

Every indicator belongs to one timing category.

Leading

Signals future economic changes.

Coincident

Reflects current conditions.

Lagging

Confirms changes that have already occurred.

MOS prioritizes Leading indicators when identifying regime transitions.

---

# Revision Policy

Many macro indicators are revised.

MOS therefore records:

Initial Release

First Revision

Final Revision

Historical Trend

Large revisions should be incorporated into the macro assessment.

Never rely solely on headline figures.

---

# Trend Evaluation

MOS evaluates trends using multiple perspectives.

Month-over-Month (MoM)

Quarter-over-Quarter (QoQ)

Year-over-Year (YoY)

Three-Month Moving Average

Six-Month Moving Average

Annualized Growth Rate

No single calculation method is universally preferred.

The appropriate measure depends on the indicator.

---

# Surprise Framework

Every major release records:

Actual

Consensus

Previous

Revision

Surprise

Market Reaction

This framework separates economic reality from market expectations.

---

# Data Quality Principles

MOS follows five quality principles.

Completeness

Use the full historical series whenever possible.

Consistency

Definitions must remain stable.

Comparability

Indicators should be comparable across time.

Transparency

Original data sources should always be identifiable.

Reproducibility

Different analysts should obtain the same result using the same data.

---

# Dashboard Principles

The Dashboard is descriptive rather than predictive.

It records what the economy is communicating.

Interpretation belongs to later engines.

Keeping data collection separate from interpretation reduces cognitive bias.

---

# Final Statement

The Data Dashboard is the foundation of MOS.

Without standardized data, there can be no standardized analysis.

Every probability, every regime assessment and every investment conclusion begins with reliable, well-defined and consistently interpreted macroeconomic data.
